# PING))) ultrasonic sensor

Parallax PING))) #28015, 3 wires, one signal pin. Status: as built.

## Purpose

Measures distance ahead of the robot. The code triggers and reads on the same pin (GPIO 16).

## Fit and position

Front centre of the top deck, hot-glued to the pan servo horn so it pans with the servo.

## Mounting points

- Hot glue to the servo horn. The board's own mounting hole is not used.
