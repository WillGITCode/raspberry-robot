# USB SSD in its enclosure

USB 3 SSD in an enclosure, model TBD. Status: planned.

## Purpose

Boot and storage drive for the Pi 4 (p2 decision 4). It plugs into one of the Pi's USB 3 ports and is powered from the Pi.

## Fit and position

On the top deck, near the Pi case, in a printed holder. Exact position TBD. Its cable runs to a Pi USB 3 port.

## Mounting points

A printed holder bolted through the existing deck slots with M3 screws (decision 4). The holder is not designed yet.
